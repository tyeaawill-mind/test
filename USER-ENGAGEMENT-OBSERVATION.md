# V20.0 user engagement observation guide

## Scenario being tested
A returning mindRID user has expressed strong anticipation for Mind Compass and impatience with releases that contain preparation work but no visible user benefit. V20.0 is intended to test whether a user can move from that anticipation into a meaningful first use.

## Observe manually; do not covertly track
1. Can the user find Mind Compass from Home without instruction?
2. Do the four directions make sense without explanation?
3. Does the user understand the difference between selecting a direction and beginning a session?
4. Does the user save a waypoint, and is the purpose clear?
5. Does the weekly summary feel useful, neutral, and non-judgmental?
6. Does the user return to a waypoint or begin another session voluntarily?
7. What feels missing, confusing, slow, or emotionally intrusive?

## Record only with explicit consent
- Task completed / not completed.
- User-described confusion or expectation mismatch.
- Voluntary return behavior observed during a consented test session.
- User's own rating of usefulness, clarity and sense of control.

Do not infer psychological state from time spent, text content, pauses, or navigation. Do not collect private reflections as research data without explicit informed consent. No engagement tracking is embedded in this build.

## Product learning question
Does Mind Compass help a user intentionally choose a direction, express or preserve a thought, and return to it—without needing an infinite feed, streaks, guilt, or manipulative prompts?
